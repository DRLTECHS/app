# DRL Web

## Before Deployment Checklist

1. Validate the website locally
   - Open the homepage and key pages such as About, Services, Shop, Contact, and Checkout.
   - Confirm all links work, the layout matches the premium brand style, and the pages return successful responses.
   - Check the contact form, NDA acceptance, and cart/checkout flows.

2. Review content, branding, and legal details
   - Confirm the DRL Techs / DRL Solutions branding is consistent across the site.
   - Verify company details, phone number, address, company president, and NDA wording are correct.
   - Ensure footer links, social icons, and page copy are final and ready for launch.

3. Prepare the production push
   - Stage the final files with git.
   - Commit the production-ready updates with a clear message.
   - Push to the main branch and trigger deployment on the hosting platform.
